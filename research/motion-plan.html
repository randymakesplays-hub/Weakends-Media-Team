Three loops, one machine

The full story-mode plan for the three service animations — concepted from Randy's vision, torn apart by three critique lenses per concept (seven-figure credibility, 60fps performance, 4-second clarity), rebuilt against every finding, then unified into one motion language. 16 agents, 0 fabricated numbers, every loop seam verified mathematically. Ships as pure CSS/SVG inside the live design — no video files, nothing heavy.

00 · The shared law

One motion system, three stories

Every panel obeys the same physics, so the site reads as one hand — while each animation opens with its own signature: a single small lit point of its accent color (purple caret · ember REC dot · green LIVE dot).

The clock

One 12.000s master loop per panel. Chapters are percentage bands, never chained animations — the loop seam cannot drift by construction.

Easing

Two curves rule everything: the site's accordion curve cubic-bezier(.2,.7,.2,1) for decisive moves, a breath sinusoid (.37,0,.63,1) for all camera drift. One documented exemption max per animation.

Camera

Perspective 1100px (1300px mobile), elevated ~315° light from upper-left, rotation never past 22° composed, near-planar clamp on phones so 11px labels render crisp.

Depth ladder

Shared z-planes: back −120px, shadows −90…−40, story at 0, floaters +30…+70, payoff plane +90px — rationed to one element at a time.

Color

Identical neutrals everywhere. One accent per panel, no overlap: web = purple, media = ember, lead = green. ≤6 accent marks per loop, never two at full strength at once.

Honesty

No fabricated metrics, no cloned platform UI. Data appears as "—", abstract bars, stylized marks. The machine is demonstrated, results are never invented.

Also law: reduced-motion visitors get a designed still tableau (not a blank frame), the no-JS default state IS that tableau, animations pause off-screen, and every text label sits in a fixed box so font loading can't shift the scene.

Craft calls that survived the critics

  • The flip card is a sibling of the bezel, never inside overflow — the one DOM structure that keeps 3D alive; all clipping lives inside 2D faces.
  • "Galaxy" rendered as premium dimensionality — four drifting depth-dust motes on divisor clocks, parallax layers, orbital camera — no literal starfield on the warm off-white card.
  • Flash and sheen are non-rotating overlays at the card silhouette — a glow riding the card would be edge-on exactly when needed.
  • ~55 DOM nodes of 70 budget; transform/opacity only; mobile clamps the orbit to ±2° and thickens bars so the story reads at 340px.

02 · Media Management

Accent: ember · 12s loop · 5 chapters

"One Take, Seven Days"

One take at the mic becomes a week of published content: the camera pulls back from a live recording to reveal the edit already underway — a playhead slices the session into clips that fly to the platforms, and the loop holds on the week's attention climbing.

Craft calls that survived the critics

  • The human problem, solved: over-the-shoulder desk diorama — foreground mic silhouette, screen glow, the creator implied. Premium at any size; never a stick figure.
  • The magnified opening uses a counter-scale authoring trick so mono text rasterizes native-crisp at 6.6× zoom.
  • Platform tiles are generic stroked glyphs, not cloned logos; engagement is abstract bars, not fake counters.
  • Mobile gets its own explicit layout (not a naive shrink): flat push camera, larger chips, the desk back-plane dropped.

Craft calls that survived the critics

  • Causality in one unbroken chain: ad → reach → funnel → pipeline → curve. No beat is decoration; every chapter is something the buyer pays for.
  • The chart is a stepped line rising off the pipeline's real columns — not a random stock squiggle; the geometry itself argues the case.
  • Leanest of the trio (~9 elements) — it reads instantly at 340px with the camera clamped near-planar.
  • Zero bespoke easing curves permitted — this panel is pure house physics.

04 · Build readiness

What the build session ships first

  • Shared CSS token partial — neutral ladder, three accents, the two easing curves, the 12s clock, duration steps
  • Shared ~30-line runtime helper — IntersectionObserver pause, font-ready gating, the no-JS tableau contract
  • Page-level font preload for JetBrains Mono (decided once, not per panel)
  • Build-time verification — flip-angle reset assertions, keyframe 0%=100% parity check on every 12s timeline
  • Loop-seam QA — frame-diff t=11.96s vs t=0.04s per panel; accent-census sampling; shadow-clip check at 340px
  • 4:3 work-card crop spec — each animation's designated still frame doubles as its card export
  • Playback policy — each panel starts at 0% on first view, pauses off-screen, no cross-panel sync
  • Accessibility — aria-hidden dioramas + a one-sentence hidden text pitch per panel
